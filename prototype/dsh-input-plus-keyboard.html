DSH Input+ 键盘状态机

这个原型只验证一个问题：候选层、输入历史、IME 和双次 Escape 同时存在时，按键是否符合 Claude Code / Codex 的输入区习惯。

状态只保存在当前页面内。双次 Escape 时间窗暂设 600ms，仅用于比较手感，不代表最终参数。

自由操作

键盘也可以直接操作：Enter 提交，Shift+Enter 换行，↑/↓ 或 Ctrl+P/N 浏览，Esc Esc 清空并可召回。
